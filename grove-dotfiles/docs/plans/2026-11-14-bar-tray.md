# Bar Menu-Bar Tray Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A tray pill in the Grove bar that lists other apps' menu-bar items (hidden behind the Grove bar) and opens them, with a count and a hide list.

**Architecture:** Pure rules (which items show, their keys, row text, order, count, hide list) live in GroveKeysCore `TrayItems`. Grove Keys reads MenuBarAgent's accessibility tree through the existing `StatusItemLocator`, extended to list every item, and presses items through one shared AX helper that the WireGuard and OneDrive openers also move onto. A `TrayWatcher` writes `$GROVE_STATE/tray` (the count) on events only; the dropdown is a Grove Keys bar panel.

**Tech Stack:** Swift 6, SwiftUI + AppKit, ApplicationServices (AX), Swift Testing; bash + bats for SketchyBar.

**Spec:** grove-dotfiles/docs/specs/2026-11-14-bar-tray-design.md

## Global Constraints
- Order `tray · cpu/mem · cloud · vpn · wifi+bt · sound · power · clock`; item `tray`, pill `pill.tray`, event `tray_change`, panel `tray`; state file `$GROVE_STATE/tray` holding the count (one line, an integer), written only on change, removed on stop; missing file → symbol without a count; label hidden at 0, fixed width.
- Pill icon: one SF Symbol drawn by `icons/make.swift` as `tray` (dark and light), fg colour, no state colour.
- Shown items: every status item in MenuBarAgent's tree except those owned by MenuBarAgent itself, by any `com.apple.` bundle id, or by SketchyBar; native left-to-right order; an app with several items gives several rows.
- Item key: `<bundleID>#<AXIdentifier>` when the identifier is non-empty and differs from the item's title and description; otherwise `<bundleID>#<index among that app's items>` (0-based).
- Row text: `AXTitle`, then `AXDescription`, then `AXHelp`; the first non-empty one that isn't the app's name; read only for listed items' own elements, every AX element timed (0.5 s).
- Opened: a new `AXMenu` or window owned by the item's pid within 1 s of the press; else press the wrapper once (same test); else activate the app.
- Default hidden: `com.projectgrove.keys`, `com.projectgrove.themes`, `bobko.aerospace`. Hidden list in `$GROVE_STATE/tray-hidden`, one key per line; missing file → defaults; written by Grove Keys only.
- Count freshness: app launch/quit (2 s settle), the panel opening, an AX observer on MenuBarAgent's windows (`kAXCreatedNotification`, `kAXUIElementDestroyedNotification`, `AXChildrenChanged`… whichever it emits); never a timer.
- Copy: "Open", "Hide from tray", "Show in tray", "Bring <App> forward", "Hidden (n)", "Menu Bar Settings…", "No other menu-bar items", "Grove Keys needs Accessibility permission", "Privacy Settings…".
- Menu Bar Settings link: `x-apple.systempreferences:com.apple.ControlCenter-Settings.extension` (fallback: System Settings).
- grove-ui skill (`GroveMenuList` for the row menu, PanelKit panel). Invented app lists in fixtures/samples (generic names, `com.example.*` ids). GroveKeys binary ONLY with `--render-panel`, `--render-keys`, `--render-aerospace`, `--check-menu`; never press other apps' UI, never launch/quit/install apps, never reload the real SketchyBar. Renders to a private folder. Never commit them; never touch `config/grove-keys/keys.toml`.
- Commits: `area: summary` + body + `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`, by explicit path.

## Review Focus
1. An app whose item has no identifier and two items (or an identifier equal to its changing status text) must keep its hide state across status changes and relaunches (Task 1 `keysStayStableWhenStatusTextChanges`).
2. A hung or slow app must not freeze the tray or the bar: every AX read is timed and listing runs off main (Task 2 step; Task 4 the panel shows the last list at once).
3. A burst of app launches (login) must coalesce into one listing, not one per app (Task 3 `burstOfLaunchesListsOnce` on the settle rule).
4. The AX observer must be torn down and re-attached when MenuBarAgent restarts (new pid), and removed on stop (Task 3 step).
5. Pressing an item whose app quit between listing and click must not crash or hang; it falls back to nothing more than closing (Task 2 `pressOfAGoneItemFails`).
