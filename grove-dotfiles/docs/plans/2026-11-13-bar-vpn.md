# Bar VPN Pill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A grove-lab VPN pill in the Grove bar that shows the tunnel's state and starts/stops it through the WireGuard app's macOS VPN configuration, with a dropdown like the others.

**Architecture:** Grove Keys' Core parses `scutil --nc status` output into a state, an icon and a status line; SketchyBar gets a `vpn.lab` item in its own pill polling scutil; Grove Keys draws the dropdown and runs `scutil --nc start|stop`.

**Tech Stack:** Swift 6, SwiftUI, Swift Testing; bash + bats.

**Spec:** grove-dotfiles/docs/specs/2026-11-13-bar-vpn-design.md

## Global Constraints
- Service name `grove-lab`; commands `scutil --nc status|start|stop "grove-lab"`.
- Order `cpu/mem · vpn · wifi+bt · sound · power · clock`; item `vpn.lab` in pill `pill.vpn`; icons `vpn-off`, `vpn-connecting`, `vpn-on` (SF Symbol `lock.shield`; grey / yellow / purple); the existing `vpn` icon untouched.
- Copy: `grove-lab VPN`; `Connected · <address> · since <HH:MM>` (parts left out when unknown); `Connecting…`; `Disconnecting…`; `Not connected`; after a start or stop that didn't happen (or scutil failed), in yellow: `Didn't start · see WireGuard` / `Didn't stop · see WireGuard`; `Import warden-air.conf into WireGuard as grove-lab`; footer and not-set-up button `Manage Tunnels…` (WireGuard's status-item menu, pressed through Accessibility); its fallback, in yellow: `Grove Keys needs Accessibility permission` with `Privacy Settings…`, or `WireGuard's menu didn't open`.
- Fixtures and samples use `10.0.0.2`, never a lab address; nothing reads `warden-air.conf`.
- grove-ui skill. The GroveKeys binary ONLY with `--render-panel`, `--render-keys`, `--render-aerospace`, `--check-menu` (anything else starts a second app and breaks the owner's Caps Lock mapping). Never reload the real SketchyBar, run the installed apps, install, or start/stop a real VPN. Never commit `artifacts/`; never touch `config/grove-keys/keys.toml`, `config/grove/local.env`.
- Commits: `area: summary` + body + `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`, by explicit path.

## Review Focus
1. `scutil` printing `No service`, an error, or nothing must give a grey pill and the setup line, never a crash (Task 1 `missingServiceIsNotSetUp`).
2. A click while a start is already under way must not send stop/start twice (Task 2 step: the switch is disabled while connecting/disconnecting).
3. The pill's 10 s poll must not stack if scutil stalls (Task 1 bats: the plugin uses `sb_timeout`).
4. A reload with the VPN dropdown open keeps its pill filled (Task 1 bats via `sb_panel_open`).
5. The status line with no address or no connect time drops those parts cleanly ("Connected" alone) (Task 1 `connectedWithoutDetails`).
