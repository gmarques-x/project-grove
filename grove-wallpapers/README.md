# grove-wallpapers

Desktop wallpapers for Project Grove, 2880 × 1864, two for each of the six Everforest schemes: `wallpaper-project-grove-<scheme>.png` (the Project Grove lockup, the default) and `wallpaper-avatar-<scheme>.png` (the avatar's tree-ring drawing), each on that scheme's background colour. Switching scheme sets the matching picture on every screen; choose between the two sets in the Grove Themes gallery or with `grove-themes wallpaper grove` or `avatar`. See [Themes](../docs/manual/04-themes.md) in the manual.
