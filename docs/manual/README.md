# The Grove manual

For someone who has just installed Project Grove and wants to know what to press. Each chapter is short and says what to do, not how it is built.

| Chapter | What it covers |
| --- | --- |
| [1. Getting started](01-getting-started.md) | What installing does to your Mac, what it asks for, and the first five minutes |
| [2. The desktop](02-the-desktop.md) | Workspaces, moving and tiling windows, floating windows, and the bar |
| [3. The Grove menu](03-the-grove-menu.md) | The pine menu, the Grove Launcher on ⌘Space, and adding your own rows |
| [4. Themes](04-themes.md) | Switching between the six schemes, the logo and wallpaper, and what follows the scheme |
| [5. Hotkeys](05-hotkeys.md) | The Hyper key, every shipped binding, changing them, and the cheat sheet |
| [6. The terminal](06-the-terminal.md) | Ghostty, the prompt, the shell's shortcuts, and Yazi |
| [7. Updates and undo](07-updates-and-undo.md) | `grove update`, `grove check`, `grove about`, "needs you", and removing Grove |
| [8. Coming from stock macOS](08-coming-from-stock-macos.md) | Where the menu bar, the Dock, Mission Control and the status menus went |

## Keys used in this manual

| Glyph | Key |
| --- | --- |
| ⌥ | Option |
| ⇧ | Shift |
| ⌃ | Control |
| ⌘ | Command |
| ↩ | Return |
| ⌫ | Delete (backspace) |
| Hyper | Caps Lock, held down |

In a hurry: hold Caps Lock for half a second to see the cheat sheet, or press ⌘Space and type what you want.
